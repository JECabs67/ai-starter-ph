# AI Starter PH

Simple AI starter guide for Pinoys. Pick a role and get a Taglish starter plan: 3 free AI tools, 1 task today and a 7-day path.

Static site (HTML/CSS/JS, no backend). Served with GitHub Pages from `main` root.

- Tool links and affiliate params: edit `CONFIG.tools` in `app.js`
- Sponsor banner: set `CONFIG.showSponsorBanner = true`
- Featured/Sponsored card: edit `CONFIG.featured`
